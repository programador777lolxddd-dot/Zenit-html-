# 🚀 Zenit

**Zenit** es un lenguaje de programación en desarrollo, creado como proyecto personal para experimentar con código y aprender a programar.

🌐 **Web oficial:** https://zenit-amber.vercel.app/  
📘 **Tutorial:** https://zenit-amber.vercel.app/tutorial.html  
🧩 **Intérprete JavaScript:** https://zenit-amber.vercel.app/zenit.js

---

## ✨ ¿Qué es Zenit?

Zenit cuenta con un intérprete que permite ejecutar código escrito en este lenguaje. El proyecto también incluye una página web y un tutorial para empezar a probarlo.

Entre las construcciones que puedes explorar están:

- Mostrar mensajes con `imprimir`.
- Trabajar con variables y listas.
- Usar condiciones `if/else`.
- Recorrer elementos con bucles `for`.
- Probar ejemplos desde una página HTML que carga el intérprete.

> Zenit está en desarrollo, así que sus características y su sintaxis pueden cambiar.

## ⚡ Ejemplo

Este es un ejemplo del estilo de código que puedes probar en Zenit:

```zenit
imprimir("¡Hola desde Zenit!")
```

Consulta el [tutorial](https://zenit-amber.vercel.app/tutorial.html) para ver cómo funciona la sintaxis disponible.

## 🌐 Usar Zenit en una página web

Puedes cargar el intérprete publicado desde tu HTML:

```html
<script src="https://zenit-amber.vercel.app/zenit.js"></script>
```

Después, tu página puede utilizar la API que expone el intérprete. Revisa los ejemplos y el tutorial del proyecto para ver cómo ejecutar código Zenit.
