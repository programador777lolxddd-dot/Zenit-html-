## ✨ Bienvenido a Zenit

**Zenit** es un lenguaje de programación en desarrollo, creado para experimentar con código y construir una experiencia de programación accesible desde la web. Su intérprete está escrito en JavaScript y permite ejecutar programas Zenit en el navegador.

Este repositorio reúne el proyecto y su página interactiva. La documentación y los ejemplos están pensados para ayudarte a dar tus primeros pasos, explorar la sintaxis y descubrir qué puedes construir.

> [!NOTE]
> **Zenit está en su última versión por ahora.** El proyecto seguirá disponible para que puedas utilizarlo y aprender con él. ¡Gracias por formar parte de esta etapa!

## 🧩 ¿Qué puedes hacer con Zenit?

- 🖨️ **Mostrar mensajes** con `imprimir()` o `print()`.
- 📦 **Crear variables y constantes** con `var` y `const`.
- 🔀 **Tomar decisiones** con `if`, `else if` y `else`.
- 🔁 **Repetir instrucciones** con bucles `while` y `for`.
- 🧰 **Definir funciones** con `func` y devolver valores con `return`.
- 📚 **Trabajar con listas**, índices y recorridos.
- ➗ **Usar operadores** aritméticos, de comparación y lógicos.
- 💬 **Escribir comentarios** para explicar tu código.

## 📚 Ejemplos de código

### 1. 📦 Variables y constantes

```javascript
var nombre = "Zenit"
var activo = true
const PI = 3.14159

imprimir(nombre)
imprimir(activo)
```

### 2. 🔀 Condiciones

```javascript
var edad = 16

if edad >= 18 {
  imprimir("Mayor de edad")
} else {
  imprimir("Menor de edad")
}
```

### 3. 🔁 Bucles

```javascript
for i in 1..5 {
  imprimir(i)
}
```

### 4. 🧰 Funciones

```javascript
func doble(numero) {
  return numero * 2
}

imprimir(doble(21))
```

### 5. 🍇 Listas

```javascript
var frutas = ["manzana", "pera", "uva"]

for fruta in frutas {
  imprimir(fruta)
}
```

### 6. 💬 Comentarios

```javascript
# Este es un comentario
// También puedes comentar así

imprimir("¡Sigue experimentando!")
```

> 💡 **Consejo:** prueba los ejemplos en la web y cambia los valores. Experimentar es una de las mejores formas de aprender cómo funciona un lenguaje.

## 🌐 Usar Zenit desde una página web

Puedes integrar Zenit en tu propia página HTML cargando el intérprete publicado. **El script debe cargarse antes de llamar a la API**.

### 1. Carga el intérprete

Añade esta línea en tu HTML, preferiblemente antes del script que ejecuta tu programa:

```html
<script src="https://zenit-amber.vercel.app/zenit.js"></script>
```

### 2. Ejecuta código Zenit desde JavaScript

Una vez cargado el intérprete, puedes pasarle el código como texto:

```html
<textarea id="codigo">
imprimir("¡Hola desde mi web!")
imprimir(2 + 3)
</textarea>

<button id="ejecutar">▶ Ejecutar Zenit</button>
<pre id="salida"></pre>

<script src="https://zenit-amber.vercel.app/zenit.js"></script>
<script>
  document.getElementById("ejecutar").addEventListener("click", () => {
    const codigo = document.getElementById("codigo").value;
    const salida = document.getElementById("salida");

    try {
      const resultado = window.Zenit.ejecutar(codigo);
      salida.textContent = resultado ?? "Programa ejecutado.";
    } catch (error) {
      salida.textContent = "Error: " + error.message;
    }
  });
</script>
```

> [!IMPORTANT]
> Este ejemplo presupone que la versión publicada de `zenit.js` expone `window.Zenit.ejecutar(codigo)`. Si el intérprete escribe la salida directamente en la página o devuelve un formato diferente, adapta la presentación de `resultado` a la API real.
